# 編集方針

## 何をつくっているのか

「語学を勉強するために文章を読む」のではなく、
**「世界で起きている面白いことを知りたいから、その国のことばで読む」**
という学習体験をつくります。

読者が「この表現は面白い」「使ってみたい」「なぜこの文法になるのだろう」「誰かにこの話をしたい」
と思える内容を最優先します。

---

## 制作手順

新しい号は、いきなり書き始めません。

1. **リサーチ** — 直近7日間を、各言語の**現地語の情報源**で調べる。
   日本語記事を外国語に訳すのではなく、最初からその言語で調べる。
2. **候補集め** — 4言語それぞれから幅広く。
   政治・戦争・経済だけに寄せない。文化、食、スポーツ、科学、暮らし、その土地らしい話も探す。
3. **評価** — 今週性／世界的な重要性／面白さ／日本ではあまり紹介されていないか／その国らしさ／
   語学教材としての価値／語彙・文法の豊かさ／会話の話題としての強さ／情報源の信頼性。
4. **構成案（TOC）を提示して承認を得る。**
5. 承認後に執筆 → Language Deep Dive → 会話・音読・演習 → 事実と出典の再確認。
6. `node tools/validate.mjs` → `node tools/build-master.mjs` → MASTER EDITORIAL VERSION を校正。

## 記事を書くときの原則

### 事実
- 存在しないニュース・人物・発言・数字・研究・URLを作らない。
- 確認できない情報は載せない。事実と意見を分ける。
- 重要な事実はできるだけ複数の信頼できる情報源で確認する。
- 速報段階で不確かなことは、不確かだと明記する（英語なら `is expected to`、
  中国語なら `据…报道`、そのニュアンスごと教材にできる）。

### 著作権
- 情報源の記事をそのまま訳したり転載したりしない。
- 報道された**事実**を調べたうえで、学習記事としてゼロから書き起こす。
- 元記事の構成や言い回しを模倣しない。長い引用をしない。
- 発言の引用は、報道された発言そのものに限り、短く、必ず出典を添える。

### 難易度
- 初級後半〜中上級。
- 不自然に簡単な教材文にしない。実際のニュースで使われる自然な言語を基本にする。
- 難しい表現は**排除するのではなく、丁寧に説明する**。
  「簡単な語に置き換える」より「自然な表現を使って、それを解説する」。

## 語学解説

語彙数・表現数に**上限を設けません**。「Vocabulary 5個」のような数量制限は禁止です。
判断基準はただ一つ、**日本人学習者にとって説明する価値があるか**。
ただし項目数を増やすためだけに極端に基本的な語を並べる必要はありません。

解説は原則として日本語で行います。外国語を外国語だけで説明する辞書形式にはしません。
読者が「なぜこの意味になるのか」「なぜこの文法を使うのか」「どんな場面で使えるのか」まで
理解できることを目指します。

### 言語ごとに必ず見るところ

**英語** — 句動詞、イディオム、コロケーション、時制、冠詞、前置詞、関係詞、分詞、助動詞、
仮定法、報道英語の型（断定回避・発言の帰属）。英米差が意味を持つときは説明する。

**中国語** — 簡体字・普通話。漢字／拼音／声調／品詞／語順／量詞／離合詞／成語／口語／ネット用語。
**日本語と同じ漢字で意味が違う語は必ず取り上げる**（表示・结构・比重・力争・会见・培养・检讨…）。
日本人が漢字から意味を誤解しやすい語を積極的に拾う。

**スペイン語** — 名詞の性、冠詞、活用、時制（点過去と線過去）、接続法、ser/estar、por/para、
再帰動詞、目的格代名詞、`se` の用法。**スペインと中南米の差**（ustedes/vosotros、voseo、
現在完了と点過去、語彙）は必ず示す。スペインだけに偏らない。

**フランス語** — 名詞の性、冠詞、活用、時制、接続法、条件法（時制の一致）、代名詞（とくに `dont`、
`celui`、`en`、`y`）、前置詞、使役の `faire`、リエゾンとアンシェヌマン、書き言葉と話し言葉の差。
フランス以外（ベルギー、スイス、カナダ、アフリカ）の話題や語形も扱う。

### 翻訳について
全文に訳を付ける場合でも直訳だけにしません。学習価値の高い文では
「直訳するとこうなるが、日本語として自然にするとこうなる」という**差そのもの**を説明します。
`literal` / `ja`、`SENTENCE BREAKDOWN` の `literal` / `natural` / `nuance` がその場所です。

## 完成前のチェック

- [ ] 4言語すべてが収録されている
- [ ] 特定地域に偏っていない
- [ ] Hard News だけになっていない
- [ ] 現地語の情報源を調査している
- [ ] 記事は独自に執筆されている（翻訳・転載でない）
- [ ] 語彙解説・文法解説・構文解説が十分にある
- [ ] 日本人が間違えやすいポイントを説明している
- [ ] 言語ごとの文化的ニュアンスを説明している
- [ ] 出典が確認されている／URLを捏造していない／公開日を確認している
- [ ] 学習者にとって「面白い」内容になっている

機械的に検査できる項目は `node tools/validate.mjs` が見ます。
残りは人の目で確認してください。
